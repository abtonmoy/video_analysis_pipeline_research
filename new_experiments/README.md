# AdaFrame Evaluation Suite

This directory contains the final validation experiments for the AdaFrame video analysis pipeline. These scripts execute the eight specific research tests outlined for the paper, generating quantitative metrics, tracking computational costs, and synthesizing the final \LaTeX updates.

## Experiment Descriptions

### 1. Budget Formula Ablation (`scripts/exp1_budget_ablation.py`)

Analytically simulates alternative budget formulas across the extracted pipeline results to understand the impact of the Hamiltonian Information Budget (HIB) dynamic calculation.

- **Strategies Tested:** Full AdaFrame (A), ISD-only (B), Linear duration (C), Fixed-25 (D), Energy-only (E).
- **Execution:** Mathematical re-evaluation (does not query the VLM API).

### 2. PySceneDetect Baseline (`scripts/exp2_pyscenedetect.py`)

Validates AdaFrame against a traditional scene boundary baseline. Uses PySceneDetect (Adaptive mode) to chunk videos and samples keyframes from each scene, piping the results to the Gemini API to compare downstream extraction accuracy.

### 3. DSNet Baseline (`scripts/exp3_dsnet.py`)

Integrates the state-of-the-art Deep Summarization Network (DSNet) baseline as a comparative anchor for semantic summarization.

- *Note: Fails gracefully and writes a fallback LaTeX template if the external DSNet repository is not available.*

### 4. Error-Free Intersection (`scripts/exp4_error_intersection.py`)

Isolates the strict subset of videos where *every single* baseline pipeline executed flawlessly without VLM timeouts or API rejections. Re-computes topic accuracy purely on this intersection to mathematically prove AdaFrame's performance is not artificially inflated by differential failure rates among the baselines.

### 5. Cost Breakdown (`scripts/exp5_cost_breakdown.py`)

Calculates the net economic savings of the proposed dynamic cascade. Multiplies the processing latency by cloud compute rates (RTX 4090 @ ~$0.50/hr) to find the strict computational overhead, and subtracts it from the token cost reductions realized by sparing the massive Vision-Language Model.

### 6. Claude VLM Generalization (`scripts/exp6_claude.py`)

Tests AdaFrame's provider-agnostic robustness by subbing in Anthropic's Claude 3.5 Haiku as the downstream VLM on a shared 50-video subset.

- *Note: Requires `ANTHROPIC_API_KEY` defined in the `.env` file.*

### 7. Native Video Input Mode (`scripts/exp7_native_video.py`)

Tests whether frame-wise semantic selection remains competitive against brute-force full video ingestion. Uploads the raw `.mp4` files directly to Gemini 2.5 Flash's native video API.

### 8. Limitations & Future Work Update (`scripts/exp8_limitations.py`)

Aggregates the comparative data from Experiments 6 and 7 to programmatically generate the accuracy statistics required for the final "Limitations" section of the document.

---

## Technical Infrastructure

- `scripts/vlm_retry_utils.py`: Centralized API orchestrator that wraps all VLM calls. Inherently catches transient networking errors and saves failed extractions to a persistent queue on disk (`results/retry_queue`).
- `scripts/generate_shared_50.py`: Standardizes a universally shared subset of 50 test videos to ensure fair alignment between heavily rate-limited experiments (Claude and Native Video).
- `scripts/assemble_paper_updates.py`: Automatically parses the metric drops generated by the above scripts and stitches them into identically formatted `%%PLACEHOLDER` LaTeX paragraphs, outputting `paper_updates_final.tex`.

## Execution Workflows

1. **Verify Sandbox:** `bash scripts/run_tests.sh`
   Runs a mock end-to-end execution across 5 local videos using API keys loaded from the root `.env` file to ensure the code executes gracefully.
2. **Full Research Evaluation:** `bash scripts/run_all.sh`
   Runs the complete benchmarking suite over the full 1,704 dataset to gather formal data.
3. **Draft Paper:** `uv run python scripts/assemble_paper_updates.py`
   Extracts final figures to patch the `paper.tex`.
